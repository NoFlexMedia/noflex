# Security

Please report vulnerabilities privately, not in a public issue, through [GitHub's private vulnerability reporting](https://github.com/NoFlexMedia/noflex/security/advisories/new).

Include what you found, how to reproduce it, and the version or commit you tested. We'll confirm we've received it within a few days, keep you updated while we work on a fix, and credit you in the release that fixes it if you'd like.

NoFlex is pre-alpha, so only the latest commit on `main` is supported.
